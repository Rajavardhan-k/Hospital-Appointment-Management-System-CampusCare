\# 🏥 Hospital Appointment Management System – CampusCare Edition



> A collaborative software project to manage hospital appointments efficiently.



\---



\## 🌟 Project Overview

The \*\*Hospital Appointment Management System – CampusCare Edition\*\* is a web-based application with modules for:

\- 👤 Patient Registration

\- 👨‍⚕️ Doctor Management

\- 📅 Appointment Scheduling

\- 📜 Appointment History



This project demonstrates \*\*Git collaboration practices\*\* including branching, merging, conflict resolution, and synchronization in a team of five developers.



\---



\## 🖥️ Technologies Used

\- 🌐 HTML5

\- 🎨 CSS3

\- ⚙️ JavaScript

\- 🔧 Git

\- 🐙 GitHub
